description: Work iteratively toward the criteria in ./.goal until all are verifiably met
---

Read the `.goal` file at the repository root. It defines the deliverable and hard completion
criteria (C1–C6), anti-overfit rules, and "not finished if" conditions.

Work toward it with rapid iteration:

- Pick the highest-leverage next step yourself; do not ask for direction.
- Expect to delete and rewrite code many times; do not preserve dead ends.
- Verify criteria only with fresh command output on current code — never from memory,
  never from output produced by an earlier code version.
- Keep a one-line-per-entry scratch log of failed ideas (probe/rule attempts and why they
  failed) under `scratch/`.
- Commit working checkpoints as you go.

Before claiming completion, re-read `.goal` and walk every criterion, including the
"Not finished if" list. If any item is unverified on the latest code, you are not done —
continue working instead of stopping.
